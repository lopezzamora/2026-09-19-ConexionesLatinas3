# Ficha de adaptación y prueba
## Mi asistente para relaciones profesionales

Completa esta ficha para adaptar, probar y mejorar tu asistente. Puedes trabajar en pareja, idealmente con alguien que no conocías antes.

Usa nombres ficticios, iniciales o situaciones realistas. No uses datos privados ni información confidencial.

## 1. Elige una situación

* Situación profesional o comunitaria:
* Persona, área o comunidad que quiero explorar:
* Punto de conexión que conozco:
* ¿Es una situación ficticia o realista sin datos sensibles?

## 2. Define tu intención

* ¿Qué quiero aprender?
* ¿Por qué me interesa esta conversación?
* ¿Qué puedo aportar?
* ¿Qué sería un resultado útil, aunque no produzca un empleo?
* ¿Qué tono quiero utilizar?

## 3. TCREI

### T — Tarea

¿Qué quiero que haga el asistente?

> Ejemplo: Ayúdame a preparar un coffee chat de aproximadamente 30 minutos.

### C — Contexto

¿Cuál es mi situación, objetivo y restricción principal?

### R — Referencias

¿Qué información, ejemplo o tono debería considerar?

### E — Evaluar

¿Cómo sabré si la respuesta es útil?

Marca lo que corresponda:

* [ ] Identifica un punto de conexión relevante.
* [ ] Propone tres temas o preguntas concretas.
* [ ] El script muestra preparación sin sonar rígido.
* [ ] Suena genuino y no transaccional.
* [ ] Respeta el tiempo y los límites.
* [ ] No inventa información.
* [ ] Distingue hechos, inferencias y preguntas.
* [ ] Propone una continuidad natural.

### I — Iterar

¿Qué cambiaré después de probar?
