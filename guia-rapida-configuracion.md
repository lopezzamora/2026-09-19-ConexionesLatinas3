# Guía rápida de configuración
## Mi asistente para relaciones profesionales

Esta guía te ayuda a poner en marcha una primera versión de tu asistente para preparar conversaciones profesionales con sentido.

La ruta es:

**Descargar → Copiar → Adaptar → Probar**

No necesitas experiencia técnica avanzada. Puedes trabajar en pareja, idealmente con alguien que no conocías antes, usando una situación ficticia o realista sin datos privados.

## 1. Descarga los recursos

El paquete principal contiene:

* `guia-rapida-configuracion.md` — esta guía.
* `prompt-base.md` — prompt base en español, listo para personalizar.
* `ficha-adaptacion-prueba.md` — hoja para adaptar, probar y mejorar el asistente.

## 2. Elige tu ruta

### Ruta verde — Gemini + Gem

Usa esta ruta si tu cuenta muestra la opción para crear un Gem:

1. Abre Gemini.
2. Crea un Gem o utiliza uno existente para el ejercicio.
3. Copia el contenido de `prompt-base.md` en las instrucciones.
4. Personaliza el prompt con la ficha.
5. Prueba una situación concreta.

### Ruta amarilla — Chat normal de Gemini

Si no puedes crear un Gem:

1. Abre un chat normal de Gemini.
2. Copia el prompt base en el chat.
3. Añade el contexto de tu situación.
4. Guarda tu versión del prompt para reutilizarla.
5. Prueba y mejora la respuesta.

### Ruta roja — Sin acceso o con bloqueo técnico

Si no tienes acceso o encuentras un bloqueo:

1. Completa la ficha.
2. Redacta tu versión del prompt.
3. Usa la demostración de la facilitadora como referencia.
4. Continúa la prueba después del taller.

Todas las rutas deben producir una primera versión útil, aunque no termines con un Gem configurado durante la sesión.

## 3. Define un caso seguro

Elige una situación profesional o comunitaria:

* Una persona o área que te gustaría conocer.
* Un posible punto de conexión.
* Algo que quieres aprender.
* Un tono que te represente.

Puedes usar un nombre ficticio o una situación realista sin datos sensibles. No compartas información de tu cuenta ni conversaciones privadas completas.

## 4. Prueba el asistente

Pídele que te ayude a producir:

1. Un punto de conexión.
2. Tres temas o preguntas para conversar.
3. Un script breve para abrir, pedir la conversación o cerrarla.
4. Un próximo paso claro y respetuoso.

Revisa que la respuesta:

* Distinga hechos de inferencias.
* No invente información.
* No suene genérica, vendedora o manipuladora.
* Respete tu voz, el tiempo de la otra persona y la privacidad.
* Deje espacio para escuchar y continuar la conversación naturalmente.

## 5. Itera

Cambia una sola instrucción y vuelve a probar. Registra:

* Qué cambiaste.
* Qué esperabas mejorar.
* Qué cambió en la respuesta.
* Qué conservarás para la siguiente versión.

Scheduled Actions y Google AI Studio son extensiones opcionales. No son necesarios para completar el ejercicio principal.
