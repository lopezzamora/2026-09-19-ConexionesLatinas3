## Sobre este paquete

Este paquete acompaña el taller y te ayuda a construir una primera versión de un asistente para preparar conversaciones y relaciones profesionales con sentido.

La meta no es aprender una herramienta por aprenderla. La meta es salir con:

* Un punto de conexión.
* Temas de conversación.
* Un script breve.
* Un próximo paso concreto.
* Una mejora para seguir iterando.

El asistente ayuda a prepararte; no reemplaza tu voz, tu criterio ni las conversaciones humanas.

## El paquete incluye

### Guía rápida de configuración

`guia-rapida-configuracion.md`

Pon en marcha tu asistente paso a paso. Explica las tres rutas de participación:

* **Ruta verde:** Gemini + Gem.
* **Ruta amarilla:** prompt en un chat normal de Gemini.
* **Ruta roja:** completar la ficha y continuar después si existe un bloqueo técnico.

### Prompt base en español

`prompt-base.md`

Instrucción inicial lista para personalizar. Ayuda a identificar puntos de conexión, proponer temas, preparar scripts, reducir la parálisis por análisis y definir un siguiente paso respetuoso.

### Ficha de adaptación y prueba

`ficha-adaptacion-prueba.md`

Hoja de trabajo para elegir una situación, estructurar la solicitud con TCREI, probar la respuesta, evaluarla y cambiar una sola instrucción en la siguiente iteración.

## Cómo usar este paquete

1. **Descargar** los tres recursos.
2. **Copiar** el prompt base en Gemini o en un Gem.
3. **Adaptar** la situación, el objetivo, el punto de conexión, el tono y los límites usando la ficha.
4. **Probar** la respuesta y revisar si produce un punto de conexión, temas, script y próximo paso.
5. Cambiar una sola instrucción y volver a probar.

## Qué debe producir el asistente

Para una situación concreta, el asistente debería ayudar a crear:

* Un punto de conexión basado en hechos.
* Tres temas o preguntas genuinas.
* Un script breve para presentarse, pedir una conversación o cerrar un coffee chat.
* Un siguiente paso claro y no invasivo.
* Una reflexión sobre qué revisar o mejorar.

Los scripts deben sonar preparados, pero no rígidos ni memorizados. Deben dejar espacio para escuchar y para que la relación se desarrolle naturalmente.

## Trabajo en parejas

Idealmente trabaja con alguien que no conocías antes de la sesión. Elijan una situación ficticia o realista sin datos sensibles y compartan al final qué construyeron y qué mejoró.

## Privacidad y límites

* Usa nombres ficticios, iniciales o situaciones realistas.
* No introduzcas datos migratorios, credenciales, información financiera, información médica ni información confidencial.
* No incluyas conversaciones privadas completas.
* Si usas un perfil público de LinkedIn, verifica los hechos y no infieras información que no aparece.
* Revisa y edita cualquier script antes de enviarlo.
* No compartas información de tu cuenta.

## Material adicional para pruebas

**Prompts Prueba Gem Personaje Laura** (`prompts_prueba_gem_personaje_laura.md`) contiene escenarios ficticios para validar el comportamiento de la Gem: petición vaga, punto de conexión, temas, script de coffee chat, seguimiento, bilingüismo, privacidad e iteración.

Este documento sirve para preparación y pruebas de calidad. No es necesario para completar el ejercicio principal de participantes.
