# Recursos para participantes

**Speaker:** [Sandra Lopez-Zamora](https://www.linkedin.com/in/slopezza/), Senior AI/ML Engineer en AI Professional Services en [Pythian](https://www.pythian.com/). 

Este repositorio acompaña el taller y te permite continuar trabajando después de la conferencia. Aquí encontrarás los materiales para construir una primera versión de un asistente que te ayude a preparar conversaciones y relaciones profesionales con sentido.

## Qué necesitas

* Una cuenta personal de Google/Gmail.
* Un navegador actualizado.
* Acceso a Gemini en `gemini.google.com`.
* No necesitas experiencia técnica avanzada.

La ruta principal usa productos gratuitos de Google disponibles para personas con una cuenta personal. La disponibilidad de algunas funciones puede variar según la cuenta, el país o la configuración. Si no puedes crear un Gem, puedes completar el ejercicio en un chat normal de Gemini.

## Qué te llevarás

Al finalizar tendrás, como mínimo:

* Un punto de conexión.
* Tres temas posibles para una conversación.
* Un script breve para abrir o preparar un coffee chat.
* Un siguiente paso concreto.
* Una mejora identificada para seguir iterando.

## Cómo usar este paquete

1. Descarga o abre `prompt-base.md`.
2. Copia el prompt en Gemini.
3. Completa `ficha-adaptacion-prueba.md`.
4. Adapta el prompt a tu situación.
5. Prueba la respuesta.
6. Cambia una sola instrucción y vuelve a probar.

## Tres rutas de participación

### Ruta verde — Gemini + Gem

Usa esta ruta si tu cuenta muestra la opción para crear un Gem. Copia el prompt base, personalízalo y prueba el asistente.

### Ruta amarilla — Chat normal de Gemini

Usa el prompt en una conversación normal. Guarda tu versión del prompt para crear un Gem más adelante, si esa opción aparece en tu cuenta.

### Ruta roja — Sin acceso o con bloqueo técnico

Completa la ficha, redacta tu prompt y usa la demo de la facilitadora como referencia. El aprendizaje no depende de terminar con una configuración técnica durante la sesión.

## Privacidad y límites

* Usa nombres ficticios, iniciales o situaciones realistas.
* No introduzcas datos sensibles, conversaciones privadas completas ni información confidencial.
* Si usas un perfil público de LinkedIn, verifica los hechos y no asumas información que no aparece.
* Revisa y edita cualquier script antes de enviarlo.
* El asistente ayuda a prepararte; no reemplaza tu criterio, tu voz ni tus relaciones humanas.

## Archivos

* `prompt-base.md`: prompt inicial en español.
* `ficha-adaptacion-prueba.md`: hoja de trabajo para adaptar, probar y mejorar.

Scheduled Actions y Google AI Studio son extensiones opcionales. No son necesarios para completar el ejercicio principal.
